# Original asset record

The archipelago artwork was created with the built-in image generation tool for this project and copied into both consuming projects. Original output is 1536×1024 PNG. Workspace copies: `app/src/main/assets/art/archipelago.png` and `website/public/assets/archipelago.png`. The game loads a shared downsampled bitmap; the original remains editable by follow-up image generation. It is concept/world artwork, not a screenshot of implemented gameplay.

Generation prompt (built-in tool, not API/CLI fallback):

> Use case: illustration-story. Asset type: original landscape background for TimesQuest, a polished offline Android multiplication adventure for children 6–11. Create a richly painted panoramic fantasy archipelago, 1536x1024 landscape, soft storybook gouache with clean silhouettes, warm sunlight and deep teal ocean, mint grass, cream stone, coral flowers, lavender mountains. Four floating islands at different depths linked by tiny wooden bridges: lush welcoming meadow with a giant ancient tree and a glowing turquoise crystal; amber desert ruins; purple mushroom grove; snowy observatory. A small original friendly round teal dragon with little golden horns and a cream belly sits on a foreground rock at lower left. Beautiful premium game concept art, no existing franchise. Leave upper sky clean for app UI overlays, no text, no numbers, no letters, no UI, no watermark. This artwork will be used inside actual game map and marketing site.

The original icon is repo-native vector geometry in `marketing/icons/launcher-legacy.xml` and `marketing/icons/icon.svg`; `tools/export_icon.py` rasterises it from geometry at 114 and 512 pixels. Android uses adaptive launcher resources in `app/src/main/res/mipmap-anydpi/ic_launcher.xml`, its API 33 variant and original foreground/monochrome drawable geometry. Canvas dragon, monster, robot, chests, platforms, car and kitchen graphics are original source in SceneView; website SVG illustrations use matching original simple forms. The two short sound effects are deterministic original sine-wave compositions generated by `tools/generate_audio.py`, with no third-party recordings. System fonts are used without redistribution. No packaged third-party narration recording is included.

Amazon SDK is a separate third-party dependency, not original artwork; review its current licence/terms and child-data behaviour before distribution. No ownership or trademark clearance for the name TimesQuest has been claimed.
